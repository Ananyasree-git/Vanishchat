VanishChat – Self-Destructing End-to-End Encrypted Chat Room

VanishChat is a real-time web-based chat application where messages and chat rooms automatically self-destruct after a user-defined time.
It is designed with privacy-first principles, using end-to-end encryption (E2EE) so that the server never sees plaintext messages.
Traditional chat applications store messages permanently on servers, creating privacy risks.
VanishChat eliminates message persistence completely.

Core Concept

Messages exist only in memory

Messages expire automatically

Chat rooms destroy themselves

Messages are encrypted in the browser

Server only relays encrypted data
Key Features

🔐 Security & Privacy

End-to-End Encryption (AES-GCM)

No database storage

No message logs

Server never sees decrypted messages

⏳ Self-Destruction

User-defined room expiry timer

User-defined message expiry timer

Automatic room deletion

Automatic user eviction on expiry

WebSocket-based messaging (Socket.IO)

Instant message delivery

Live countdown timers
